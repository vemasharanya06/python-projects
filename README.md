## Student Task Manager — Full Stack Web Application

A simple web application that helps students manage their daily tasks.

### Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Store tasks in an SQLite database

### Technologies Used
- Frontend: HTML, CSS
- Backend: Python Flask
- Database: SQLite

### How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.
